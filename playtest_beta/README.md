## 集計とAI

40条件×2,000ゲーム。2～6人、4段階、混合、FMSなし、4人の性格別同型・単独侵入。乱数シードは20261021＋条件番号×1000000＋ゲーム番号。全条件を一つの母集団として勝率を平均しない。

0=合法手ランダム、1=記憶なし、2=記憶、3=記憶＋残存札計数。0のFMS宣言値もランダム候補に含む。1以上は候補ごとの期待値を評価し、同点は乱択。性格はbalanced / aggressive / cautious / weather / disruptive / collector。collectorは魔理沙保持に0.65の加点。固定ヒューリスティックであり、実際の技能段階や最適戦略を保証しない。

FMSなし対照は独立乱数系列。発動者勝率の主集計はイベント単位で、引分も分母に含み、同時ラウンド勝利・同時優勝は勝者に含める。優勝持分だけは同時優勝を人数で等分する。95%区間はゲームをクラスタとした比率のデルタ法近似。生存選択、対象選択、任意発動による選択バイアスがある。

通常到達できない盤面を回帰テストで手作りする場合は、目的外の枚数保存検査を呼ばない。通常シミュレーションでは全手番の解決後に25枚・10枚の保存と既知情報整合性を検査する。

## 出力

- summary.csv：条件ごとの分母付き集計。空欄のカウンタは発生0。

- fms_events.csv：発動時の人数・天候・宣言・対象札・決闘・ラウンド・ゲーム結果。
- detail_*.json：天候イベント、席・モデル別の優勝持分。
- trace_*.json：全情報デバッグログ。AIの観測入力そのものではない。
- fms_exact_fresh_hand.csv：自分の1・1以外未知の23枚を使う理論比較。実戦勝率ではない。
- manifest.json：入力とPythonのハッシュ。

カードの使用後勝率・BR所持時勝率は条件付き相関で、カードの効果量・総合強さを推定するものではない。カードの数値・本文は調整していない。
